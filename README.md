# 🫟 Slime Wars

> **A fast-paced 2-player local arena fighting game built with GameMaker.**

**Slime Wars** is a chaotic local multiplayer fighting game where two slime warriors battle in a compact arena. Move, jump, attack, collect power-ups, and outplay your opponent to claim victory.

Built with **GameMaker Studio 2**, the project focuses on responsive movement, collision detection, combat mechanics, and a fun arcade-style experience.

---

## 🎮 Gameplay

Two slime warriors enter the arena with one goal: **defeat the opponent**.

Move around the arena, jump over attacks, strike at the right moment, and use power-ups to gain an advantage.

### 🏆 Win Condition

- Each player starts with a health bar.
- Successful attacks reduce the opponent's health.
- When a player's health reaches **0**, they are defeated.
- The remaining player wins the round.

## 🧠 Core Systems

### 🏃 Movement System

Handles player movement, jumping, gravity, and arena boundaries.

### ⚔️ Combat System

Manages attacks, hitboxes, hit detection, damage, and player interactions.

### ❤️ Health System

Tracks player health and determines when a player is defeated.

### ⚡ Power-Up System

Spawns power-ups around the arena to add variety and strategic choices during combat.

### 🧱 Collision System

Handles collisions between players, attacks, platforms, and the environment.

### 🏆 Round System

Controls player defeat, victory conditions, and restarting the arena for the next round.

## 🚀 How to Run

### Open the Project

1. Open **GameMaker Studio 2**.
2. Select **Open Project**.
3. Open the `Slime-Wars-Game` project.
